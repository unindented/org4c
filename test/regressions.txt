# Regressions

This file contains tests for bugs found in ORG4C.

Emphasis at the end of a link description.

```````````````````````````````` example
[[https://x.org][a *link*]] [[u][*b*]]
.
<p><a href="https://x.org">a <b>link</b></a> <a href="#u"><b>b</b></a></p>
````````````````````````````````

Inline footnote definition with a lone CR as a line break (found by fuzzing:
heap buffer overflow).

```````````````````````````````` example
a[fn::bc]
.
<p>a<sup><a id="fnr.1" class="footref" href="#fn.1">1</a></sup></p>
<div id="footnotes">
<h2 class="footnotes">Footnotes:</h2>
<div id="text-footnotes">
<div class="footdef"><sup><a id="fn.1" class="footnum" href="#fnr.1">1</a></sup> <div class="footpara"><p>b
c</p>
</div></div>
</div>
</div>
````````````````````````````````

Too deeply nested spans.

```````````````````````````````` example
****************************************x****************************************
.
<p><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b><b>********x********</b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></b></p>
````````````````````````````````

A caption directly after a table (without any blank line) belongs to the next
element, not to the table.

```````````````````````````````` example
#+CAPTION: x
| a |
#+caption: c
#+begin_src
x
#+end_src
.
<table>
<caption class="t-above"><span class="table-number">Table 1:</span> x</caption>
<tbody>
<tr>
<td>a</td>
</tr>
</tbody>
</table>
<label class="org-src-name"><span class="listing-number">Listing 1: </span>c</label><pre><code>x
</code></pre>
````````````````````````````````

A huge list item counter is clamped (it used to overflow).

```````````````````````````````` example
1. [@5000000000] a
.
<ol>
<li value="999999999">a</li>
</ol>
````````````````````````````````

Special strings next to characters to escape, and at the end of the text
(the normal text is scanned for both at once).

```````````````````````````````` example

..&lt;.. -&lt;- -&mdash;
f&shy;
g\
<b>h--</b> i-</p>
````````````````````````````````

type as a whole word within the line).

```````````````````````````````` example

HTTPS://x.org hTTP://x :x a: b :: c
mailto:a@b.c ftp:x file:y news:z httpsx://y

.

HTTPS://x.org hTTP://x :x a: b :: c
<a href="mailto:a@b.c">mailto:a@b.c</a> <a href="ftp:x">ftp:x</a> <a href="y">file:y</a> news:z httpsx://y

````````````````````````````````

Inline source blocks and Babel calls are detected at the underscore after
"src" or "call" (looking back for them as a whole word).

```````````````````````````````` example
*https://x.org* /src_c{x}/ asrc_c{x} src_c{x}src_d{y} _call_f()_
call_f() call_f call_f(x)y $x$src_c{y} \alpha{}src_c{d} https://a.b/src_c{d}
src_c{d}
.
<p><b><a href="https://x.org">https://x.org</a></b> <i><code class="src src-c">x</code></i> asrc_c{x} <code class="src src-c">x</code><code class="src src-d">y</code> <span class="underline"></span>
 call_f y $x$<code class="src src-c">y</code> &alpha;<code class="src src-c">d</code> <a href="https://a.b/src_c%7Bd">https://a.b/src_c{d</a>}
<code class="src src-c">d</code></p>
````````````````````````````````

An inline source block or Babel call takes precedence over a subscript at its
underscore.

```````````````````````````````` example
a_b src_c{d} src_c{d}_e call_f(x)_g x_src_c{y} (src_c{y})_z
.
<p>a<sub>b</sub> <code class="src src-c">d</code> <code class="src src-c">d</code><sub>e</sub> <sub>g</sub> x<sub>src</sub>_c{y} (<code class="src src-c">y</code>)<sub>z</sub></p>
.
--fsubsuperscripts
````````````````````````````````

A radio link takes precedence over a plain link, but not over an inline source
block or Babel call.

```````````````````````````````` example
<<<http>>> <<<src>>> <<<call>>>

http://x src_c{x} call_f(y) src call http
.
<p><a id="http">http</a> <a id="src">src</a> <a id="call">call</a></p>
<p><a href="#http">http</a>://x <code class="src src-c">x</code>  <a href="#src">src</a> <a href="#call">call</a> <a href="#http">http</a></p>
````````````````````````````````

Inline source blocks and Babel calls with plain links disabled.

```````````````````````````````` example
https://x.org src_c{x} call_f(y)
.
<p>https://x.org <code class="src src-c">x</code> </p>
.
--fno-plain-links
````````````````````````````````
